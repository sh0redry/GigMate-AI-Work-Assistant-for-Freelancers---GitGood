# D-04 到最终网页交付：本批验收

2026-10-16 · Kyrie。[English](../en/role-d-final-acceptance.md)。基于已合并 #25 的 main `53991dc`；对应 [Andy 的 #29 指导](https://github.com/sh0redry/GigMate-AI-Work-Assistant-for-Freelancers---GitGood/issues/29)、[建单 #7](https://github.com/sh0redry/GigMate-AI-Work-Assistant-for-Freelancers---GitGood/issues/7)、[日历 #12](https://github.com/sh0redry/GigMate-AI-Work-Assistant-for-Freelancers---GitGood/issues/12)，保留[历史分页 #28](https://github.com/sh0redry/GigMate-AI-Work-Assistant-for-Freelancers---GitGood/issues/28) 的非阻塞限制。

## 本批交付

- 一个产品前端：无环境选择、后端地址注入、公开密码、虚构输入和备用服务。开发时只配置一个本机目标，交付使用同源 API，保留登录／CSRF。旧环境网址在读取接口前停住；旧未知审批不搬运、不删除，而是阻止新提交。虚构测试资源和测试代码保留在产品操作流程之外。
- 新建流程：读取自己的授权会话，填写摘要、未知／仅日期／具体时间和地址，分别选择客户当前原文；已有未结束工单需明确确认另开。改内容或来源会使复核失效。已准备 #26 的待接命令，但服务端能力状态关闭，不试探缺失接口、不伪造保存成功。
- 生命周期：解释合法状态流转、终态、确切版本和副作用；#27 保存关闭。地址／关键项、归单／延期、手动待办等依赖明确不可用，不替 C 另写建单／状态规则，也不绕开已知 #26 缺陷。
- 原编号业务命令：请求前保存账号／API 范围的原内容、版本、编号和变更复核展示信息；刷新、重开、退出不重发。明确复核后才核对原编号。存储获取／读／写／清理被拒，或另一页面保存了新记录时，阻止不安全写入；核对响应归属／版本后才清理。不因登录失败推断旧请求没提交。
- 独立月历／全部安排／全部工单待办，已结束工单历史、跨午夜和全天显示、方向键／Home／End、点日期和打开对应工单。离开页面／退出时中止未完成下载，旧账号的迟到文件不落入新页面。
- `GET /calendar-events/{id}.ics`：先验证登录／归属，只读，核对工单和时间版本；仅当前有效、未结束工单的正式具体时间可导出。保留稳定 UID、工单版本、UTC 时间、原时区说明、已确认地点，处理中文折行和特殊字符，禁止缓存。没有改表／迁移，也不向外部日历写入。依据 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)。手机更新／重新导入靠用户操作，不承诺客户端不重复导入。
- 账号／白名单内会话列表、安全复核记录、历史轮次、当前原文、关联工单、缺项说明和附件来源核对入口。不展示原始连接器数据包，不调用新模型。读取全历史的性能问题仍是非阻塞后续项，本批没有关闭 #28。
- 功能状态／帮助页，批准与发送分开、缺项追问原因可读。A 手动发送按独立授权使用，不伪造 C/A 执行关联。真实模型、自动建单／OCR／语音和自由生成自动回复仍明确未开放。
- 手机布局、唯一 main 区域、跳到内容链接、导航后焦点、键盘月历及普通控件 44px 高度。提供网页安装信息／图标，不安装离线聊天缓存或后台提交程序。支持的浏览器可在 HTTPS／本机地址安装，未交付原生安装器／签名。依据 [MDN 安装条件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。
- 网页容器格式检查后使用 `bundle` 编译；完整测试在发布前的固定 Python 环境执行，避免 Node 网页镜像缺测试解释器而无法构建。
