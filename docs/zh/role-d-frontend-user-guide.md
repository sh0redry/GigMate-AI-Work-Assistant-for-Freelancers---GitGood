# GigMate 前端使用手册

本地用户版，更新于 2026-10-18。这份手册讲怎么使用；实际验证见[项目进展](progress.md)。[English](../en/role-d-frontend-user-guide.md)。

## 每次怎么在自己的电脑打开

不需要团队服务器：你的电脑负责运行网页、后台、数据库和 WhatsApp 连接。API key 放在自己电脑的 `.env`，不会上传 GitHub。第一次安装按根目录 README 操作，`--init` 只用一次。已有安装保留原来的 `.env`、登录账号和手机连接，不要重新初始化或复制别人的数据。

以后每次只需打开 Docker Desktop，再在**项目根目录**打开终端。Mac/Linux 运行：

```text
.venv/bin/python scripts/start_product.py
```

Windows 运行 `.venv/Scripts/python.exe scripts/start_product.py`。然后打开 http://127.0.0.1:18780。这个命令会一起更新网页、后端和后台处理程序，检查它们的接口是否一致，通过后才提示可使用。不需要另开前端开发服务器，也不会启动虚构工单的演示版。

新安装可以在 `.env` 自己设置账号密码；未设置密码时，系统随机生成，保存在本机 `local-data/waha-a02/login.json`。已有账号密码不会改变。遇到问题不要重跑初始化，也不要删数据库或手机会话。关闭 Docker 会停止服务，但保留数据；下次启动后再运行上述命令。

## 先认识五个概念

- **工单**：一份工作的小档案，例如“陈小姐证件照”。一个聊天可以有多张工单。
- **提议**：客户或 AI 整理出的待核对内容。出现提议，不代表正式安排已经变了。
- **客户确认**：客户明确同意；你自己发的消息不能代替。
- **商户批准**：你核对后同意某个操作。批准回复仍不代表已发送。
- **回执**：系统对这次操作的记录。“已接受”不一定是“已送达”；“未知”不能当作失败重发。

## 登录、语言和连接

用维护者给你的 GigMate 账号登录；它不是 WhatsApp 手机账号。成品页没有公开测试密码、演示入口或隔离环境切换。测试在开发者自己的临时环境完成。

右上角 **中文／English／粵語** 随时切换。切换不退出登录、不清空正在填写的内容；客户原文和批准正文不会被翻译。只记住语言偏好，不把聊天发送给翻译网站。

进入 **WhatsApp 连接**，按页面扫码，发现并勾选需要处理的工作对话，明确保存授权。读取／处理授权与发送授权分开；想发消息还要单独允许对应聊天。暂停、撤权和重新连接都会重新检查当前状态。没有连接记录时联系接入负责人，不要反复扫码。

## 第一张工单怎么来

进入 **新建工单**，选已授权对话，读客户原文，填写摘要。客户没说清时间或地址就留空；只有日期的安排仍属暂定。有具体值时，勾选客户说明它的那条最新消息。已有开放工单时，另开一单要明确勾选“这是另一项业务”。

点击“核对新工单”，逐项看清，再勾选确认、保存。**AI 新单建议**仅在后端有有效建议时显示；点选只预填摘要，你仍要读原文、填写关键值并确认。不会自动替你开正式工单；没有建议可以手动操作。

## 日常处理顺序

客户只说“几点开始”，还不等于完整预约：系统会保留开始时间，显示“待复核”，也会保留同一条消息里的地址建议，不再因为时间不完整而整条处理失败。还需要问清结束时间或持续多久。核对完整时间后才能更新日历，系统不会擅自假设一小时，也不会把一个开始时间改成全天预约。

1. **业务工作台**：搜索工单，核对当前安排、来源消息和待确认变更。客户改消息后旧依据会失效。
2. **业务管理**：看今日事项，处理归单、稍后确认、资料／承诺／问题；设置工作时间与休息；核对其他字段提议。
3. **回复审批**：核对收件对话、完整正文、来源和有效期，再批准或写原因拒绝。修改正文会生成新修订，需重新批准。
4. **业务管理 → 修改回复与发送记录**：选择已批准草稿和准确连接，核对后提交。需先在连接页授权该聊天发送。提交不等于送达；关联记录保留结果。
5. **日历与待办**：看月历或全部安排。已确认且来源仍有效的正式预约可导出 `.ics`，自行导入手机／Google／Outlook。改期不会自动同步；重复导入可能重复。
6. **业务管理 → 处理待办**：核对后完成或取消。前置待办没做完时先处理依赖；完成待办不代表客户确认时间／地址。
7. **交付检查**：先处理未完成事项，再结束工单。确需带未完成事项结束时必须明确知悉。结束后可以归档，历史保留。

“快速问工作台”只支持今天安排、明天安排、等客户和待决定四类问题；不认识的问题不会猜答案。结果来自当前账号记录，可打开工单核对。

## 网络断了怎么办

刷新只是读状态，不会自动再批准／再发消息。已提交但没收到答复时，保留原编号、内容和版本；先看当前记录，再明确核对原操作。没查到回执不代表没执行，不要换编号重建工单或重发。模型结果未知时交维护者查原调用编号，也可根据原文手动处理。

服务器明确拒绝了检查清单、前置任务等操作时，不会保存半套修改；处理条件后可以重新核对提交。按钮暂不能用时，看旁边原因；不要在浏览器里绕过授权。

## 为什么状态每几秒检查却不再整页闪

业务页可见时约每 5 秒检查，仍要联网和验证权限。没变就继续展示原数据，变了只替换相关部分；不会每次清空列表。断网可标明显示上次数据，但旧数据不能授权新的业务确认；退出或换账号会清理缓存。

## 当前边界

文字模型需维护者在后端明确配置与授权；没有配置时使用手动路径。真实语音／图片识别、媒体转工单、自由 Agent 自动回复、日历持续同步和独立 exe／app 安装包尚未交付。浏览器“安装／添加到主屏幕”只是快捷入口，仍需要运行中的后端。真实手机、供应商和长期部署验收也不能由本地测试替代。
