## 已实现范围

登录后新增 **业务工作台**：工单搜索／状态筛选、字段状态与精确来源修订、全部关联会话、提议历史、明确核对后的内部排期确认、账号日历、选中工单的待办及历史。原固定样例留在明确标注的 **工单回放** 模式。搜索／筛选不会偷偷切换选中工单，被隐藏的选择仍有提示。未知值保持未提供；顾客提议、顾客确认、商户确认分别显示。

通过规范的账号所属接口加载每个关联会话及全部消息页；任一会话缺失／被拒绝，整个读取失败，不提供可写的部分快照。ChangeView 没有会话 ID，因此从精确、未撤回且归属于同一关联会话的来源修订推导确认所需上下文。缺失或跨会话的来源禁止确认。核对绑定提议内容、来源／会话版本与工单版本；刷新后数据改变会使原核对失效。必须明确勾选才能提交。只启用 main 已实现的时间安排确认；终态工单、冲突、失效提议、过期读取及其他字段不可确认。后端负责最终验证。

日历标明当前／其他工单、暂定／正式、工单版本和缓冲分钟。时刻按香港日期边界筛选，包含跨夜重叠；全天日期保留原时区／日期。冲突 ID 先查日历记录，再显示工单名称。待办区分待处理／受阻／完成／取消、截止时间、依赖和来源修订；默认隐藏历史，全部筛选保留已取消的旧准备任务。

未修改后端、迁移、契约模型、生成 schema／类型或接入模块。未实现新建／状态修改、回复审批／发送页面、通用提取、附件处理、外部日历或桌面打包。D-03／D-04 等待规范接口；独立评审及真实设备验收仍待完成。
